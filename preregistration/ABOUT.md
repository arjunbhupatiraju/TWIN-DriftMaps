# About these files

Each file is a copy of a pre-registration record kept in the project notes while the analyses were done. Registration dates, code hashes, hypotheses, criteria and amendments are copied as written. In a few files, results commentary added after the run has been shortened or left out. Every confirmatory verdict is listed in Table 2 of the paper and in transparency-table.md.

The SHA-256 prefixes refer to the scripts in analysis/ in this repository.
